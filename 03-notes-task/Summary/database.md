**The Core CRUD Operations**
`Create (Insert)`: Adding new records or data into the database. (SQL example: INSERT INTO)

`Read (Select / Query)`: Retrieving, filtering, or searching for existing data based on specific conditions. (SQL example: SELECT)

`Update`: Modifying or changing existing data records that are already stored. (SQL example: UPDATE)

`Delete (Remove)`: Removing unneeded records or data from the database. (SQL example: DELETE)

**System & Management Operations**

Beyond manipulating individual records, database management systems (DBMS) perform crucial operational tasks:

`Transaction Control (ACID)`: Ensuring that a series of database operations either all succeed together or fail completely (Atomicity, Consistency, Isolation, Durability) to prevent data corruption.

`Indexing`: Creating pointers or secondary data structures to speed up search and retrieval queries.

`Backup and Recovery`: Creating secure backups of data and restoring the database to a consistent state in case of system failures or crashes.

`Security & Access Control`: Managing user permissions, authentication, and authorization to ensure only authorized users can read or modify sensitive data.
